# Demo del portafolio

Este repositorio se conserva como fuente única de NovaRealm. La rama
`portfolio-demo` incorpora los cambios locales preparados anteriormente, sin
repetir pruebas en esta fase de publicación.

- Frontend: `front-nova-realm`.
- API: `back-nova-realm`.
- `NEXT_PUBLIC_DEMO_MODE=true` identifica los datos ficticios y anula enlaces
  comerciales salientes.
- La API mantiene la configuración de libSQL/Turso y del proveedor IA en Vercel;
  no se copian credenciales al repositorio.
- Los cambios respetan el historial y la autoría de IngenieroCui.
